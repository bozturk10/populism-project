# Generated analysis outputs

This directory is the readable output layer. It contains summaries generated from the
canonical scripts, not hand-edited analytical results.

- `reports/`: generated Markdown reports. HTML copies may be generated locally
  but are excluded from Git.
- `figures/`: standalone PNG figures used by reports.
- `tables/`: compact CSV tables used by reports and figures.

`data/processed/` remains the location for respondent-level and other machine-readable
analysis datasets. The script that creates each output is listed in
`analysis/README.md`.
